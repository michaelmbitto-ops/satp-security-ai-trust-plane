# Contributing to SATP
### Security–AI Trust Plane (SATP)

Thank you for your interest in contributing to the SATP project. SATP is a modern, flow‑centric security model designed to govern human, machine, and AI interactions across distributed systems.

This document outlines how to contribute effectively.

---

## 1. Ways to Contribute
You can contribute by:

- Improving documentation
- Adding diagrams
- Proposing enhancements
- Submitting implementation examples
- Reporting issues
- Participating in discussions
- Contributing to the reference implementation

---

## 2. Repository Structure
- `README.md` — Overview  
- `WHITEPAPER.md` — Full SATP whitepaper  
- `/diagrams/` — Mermaid diagrams  
- `/examples/` — Implementation examples  
- `/drafts/` — Future concepts and research notes  

---

## 3. How to Submit Changes
1. Fork the repository  
2. Create a feature branch  
3. Commit your changes  
4. Open a Pull Request  
5. Describe your contribution clearly  

---

## 4. Coding Standards
- Use clear, descriptive commit messages  
- Keep diagrams in Mermaid format  
- Follow SATP terminology (IEL, FCL, PGL, TEL, RAL)  
- Reference the roadmap for alignment  

---

## 5. Issues & Discussions
Use GitHub Issues for:

- Bugs  
- Diagram corrections  
- Whitepaper improvements  
- Implementation questions  

Use Discussions for:

- Architecture debates  
- Research ideas  
- SATP v2 concepts  

---
