# SATP Roadmap

This roadmap outlines planned enhancements, research directions, and implementation milestones for SATP.

---

## 1. Documentation Enhancements
- SATP GitHub Pages documentation site
- Expanded diagrams (telemetry graph, policy engine flow)
- SATP glossary and terminology guide
- Architecture decision records (ADRs)

- Trust scoring engine

## 5. SATP Policy Engine (v1.4)
